# Charter Backlog

Session modunda (`references/core/session-mode.md`) ortaya çıkan ve henüz koşulmamış charter'lar burada tutulur. Ürüne özgü backlog yerel paket dizininde tutulur; bu dosya yalnız şablondur.

Kaynak: `diff` (değişiklikten), `bug` (bulgudan), `soru` (açık sorudan). Durum: `Açık` / `Koşuluyor` / `Bitti`. Rapor: session özeti bağlantısı.

| # | Charter | Kaynak (diff/bug/soru) | Öncelik | Durum | Rapor |
|---|---|---|---|---|---|
| 1 | Keşfet … / Şununla … / Bulmak için … | diff | Yüksek | Açık | |
| 2 | | bug | Orta | Açık | |
| 3 | | soru | Düşük | Açık | |
